# UI i18n（中英切换）

**日期：** 2026-09-08  
**状态：** 已批准（用户选 A）

## 目标

修改器界面支持中文 / English；默认跟随系统语言（`navigator.language` 以 `zh` 开头 → 中文，否则英文）；可手动切换并写入 `localStorage`（键 `cfse-locale`）。

## 方案

- 轻量自研 `t()` + `locale` ref（不引入 vue-i18n）
- `el-config-provider` 切换 Element Plus `zh-cn` / `en`
- 标题栏语言切换：中文 | English
- 游戏数据名称（机体/星球/军团）保持游戏表原文（中文）
- `SaveData` 抛错用 `code`，界面 `t('error.' + code)`

## 非目标

- 不翻译游戏内专有名词数据表
- 不改主进程 dialog 系统原生语言（跟随 OS）
